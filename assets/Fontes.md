# Fontes

Toda afirmação com número, data ou atribuição no vault aponta para uma fonte. Esta página lista as fontes externas usadas, com data de consulta. Fonte interna (captura, reunião, conversa) aponta direto para o arquivo em `00-Sistema/Bruto/` ou `00-Diario/`, sem passar por aqui.

Formato: uma linha por fonte, com o que ela sustenta.

| Fonte | O que sustenta | Data de consulta |
|---|---|---|
| | | |

Regra: número sem fonte é opinião e vai marcado como tal na nota. Ao encontrar número mais recente sobre algo já registrado, atualizar a nota, registrar a mudança no log do dia e acrescentar a fonte nova aqui.
