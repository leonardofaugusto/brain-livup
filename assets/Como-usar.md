# Como usar a inbox

Despeje aqui. Sem formato, sem título bom, sem frontmatter, sem organizar nada.

Serve: texto colado de reunião, transcrição de áudio, print de conversa, link com uma linha de comentário, ideia de três palavras, reclamação, número que você ouviu num corredor.

Depois é só dizer "processa a inbox". Eu leio, classifico, escrevo nota atômica, linko, extraio tarefa, e movo o arquivo cru para `00-Sistema/Bruto/` **sem alterar uma palavra do que você escreveu**. No fim devolvo três coisas: o que criei, o que virou proposta esperando sua confirmação, e onde a captura contradiz algo que já estava no vault.

Regra minha, não sua: esta pasta termina cada sessão vazia.

Uma coisa que **não** entra aqui nem em nenhum outro lugar do vault: senha, token, chave de API, credencial. Isso vai para gerenciador de segredos. Este vault é markdown em disco e pode ir para o git.
